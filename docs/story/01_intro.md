# 01. 게임 시작 인트로 컷씬

> Phase 2 - 기획 파트 산출물 #2 (스토리)
> 작성: 기획 리더(PM) + 기획 팀원 페어 토의
> 의존: `00_story_bible.md`
> 본 문서는 게임 시작 시(타이틀 → 새 게임 클릭 후) 재생되는 인트로 컷씬의 대본을 담는다.
> 연출: 한 줄씩 페이드 인/아웃, 배경은 정적인 한 폭의 수묵화 같은 화면에 텍스트가 천천히 떠오르는 방식.

---

## 0. 페어 토의 메모

- **리더**: "인트로는 길면 안 된다. 아이들이 못 견딘다. 30초~1분 이내. 클릭으로 스킵 가능."
- **팀원**: "동의. 정보 전달은 최소화. '왜 안시성에서 버텨야 하는가'만 답하면 된다."
- **리더**: "한 폭의 그림처럼. 글자가 떨어지는 첫눈처럼 천천히."
- **팀원**: "마지막 한 줄은 양만춘의 다짐. 게임 첫 화면으로의 자연스러운 인계."

### DECISION 라벨

- **DECISION-I01**: 인트로 분량 = 본문 약 280자. 자막 7개 슬라이드.
- **DECISION-I02**: 스킵 가능. ESC 또는 클릭 시 즉시 스테이지 선택 화면.
- **DECISION-I03**: 음악은 가야금 + 잔잔한 대금. 한 음씩 천천히.

## 1. 컷씬 메타 정보

| 항목 | 값 |
|---|---|
| **재생 위치** | 타이틀 화면 → [새 게임] 클릭 직후 |
| **총 길이** | 약 45초 |
| **스킵** | ESC 또는 좌클릭으로 즉시 종료 |
| **배경** | 수묵 톤 정적 일러스트 7장 (페이드 전환) |

| **SFX** | 페이지 넘기는 소리 (한지 사각) 1회/슬라이드 |
| **자막 폰트** | 본고딕 Heavy 32px, 흰색, 외곽 그림자 |

## 4. 연출 노트 (디자인 파트 인계)

### 4.1 비주얼

- 모든 슬라이드는 **수묵 톤** — 검정·회색·옅은 청·연한 황토만 사용. 채도 낮게.
- 캐릭터는 SD 2.5등신을 유지하되 실루엣은 약간 길게 늘어지게 (정적 컷의 무게감).
- 텍스트는 자막창 없이 화면 위에 직접 떠오름. 가독성 위해 1~2px 외곽 그림자.

### 4.2 사운드

- BGM "안시의 첫눈"은 60 BPM의 가야금 솔로 + 슬라이드 5에서 대금이 한 음 합류 + 슬라이드 7에서 작은 북 한 번.
- SFX: 페이지 넘기는 소리("사각")는 슬라이드 전환 시. 활시위 "탱-"은 슬라이드 6 중간.
- 양만춘과 모용손 대사는 한 음절 보이스("음-", "예-") 정도만 입혀도 무방. 풀더빙은 비용 이슈로 보류.

### 4.3 인터랙션

- ESC 또는 좌클릭 시: 즉시 페이드 아웃 후 스테이지 선택 화면.
- 처음 한 번은 자동 재생. 두 번째 이후엔 타이틀 화면의 [인트로 다시 보기] 메뉴를 통해서만.

## 5. 픽션 표기 노트 (게임 내 표시)

게임 시작 시 인트로 종료 후 1회만 표시되는 작은 토스트:

> "이 게임의 등장인물 중 양만춘은 후대 전승에 따른 이름이며, 부장 모용손·향이 모자는 본 게임의 창작 인물입니다. 안시성 전투의 큰 줄기는 사료를 따랐습니다."

토스트는 화면 우상단에서 6초 후 자동 소멸. UI 스트링(`08_ui_strings.md`)에도 동일 텍스트 등록.
