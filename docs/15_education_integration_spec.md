## 1. 교육-메커닉 5대 원칙 (확정판) + GDD 씨앗 매핑

> 원칙은 "교육용 한국사 게임"의 가치명제(`02_concept_brief.md` §5)를 메커닉 차원에서 강제하는 헌법이다.
> 각 원칙은 GDD/기존 문서에 **이미 씨앗이 있다** — 본 스펙은 그 씨앗을 원칙으로 격상·통일한다.

### 원칙 EP1 — 흐름 보존 (Flow First)
교육 콘텐츠는 **게임 흐름을 끊지 않는다.** 학습은 보상·도감으로 *당겨* 오고, 강제 텍스트 벽으로 *밀지* 않는다.
- **GDD 씨앗**: `02_concept_brief.md` §10 "[역사 노트] 너무 띄우면 흐름 끊김 → 클리어 보상으로", `03_GDD` §1.2 매크로 루프의 "클리어 → 별 평가 → 도감" 위치.
- **귀결**: L2 결과 카드 본문 강제는 금지(앞면만 자동) — [DECISION-EDU-001].

### 원칙 EP2 — 라벨 무결성 (Label Integrity)
화면에 노출되는 **모든 역사 서술은 (사실)/[전승]/[픽션] 중 하나로 분류 가능**해야 하며, 분류는 단 하나의 SSOT(`09_codex.md` §4)를 따른다. 야사를 사실로 단정하는 텍스트는 어떤 레이어에서도 금지.
- **GDD 씨앗**: `00_story_bible.md` §5 라벨 시스템, `09_codex.md` DECISION-C02, 이미 존재하는 `08_ui_strings.md` `codex.label.*` 3키.

### 원칙 EP3 — 메커닉이 곧 사료 (Mechanic-as-Source)
핵심 메커닉은 **사료에 직접 근거**해야 하며, 그 근거가 한 번 이상 플레이어에게 노출된다. 메커닉은 "왜 이런가"의 답이 사료다.
- **GDD 씨앗**: `01_history_research.md` §9 Hook 1~8(각 후크가 "역사 근거 → 메커닉" 구조), `03_GDD` 토산/추위/복구 메커닉.

### 원칙 EP4 — 무해성 우선 (Harmless by Design)
교육 정확성과 가족 친화 톤이 충돌하면 **톤이 이긴다.** 잔혹·생매장·신체훼손 등은 본문(연구문서)에만 남고 게임에는 순화·생략한다. 단, 생략 사실 자체를 숨기지 않는다(라벨/각색 표기).
- **GDD 씨앗**: `01_history_research.md` §5.3 말갈 생매장 처리("포로가 되었다"), §8 안구부상 순화, `00_story_bible.md` §4 블랙리스트.

### 원칙 EP5 — 출처로의 다리 (Bridge to Sources)
게임이 끝나도 더 알아보고 싶을 때 **출처를 따라갈 수 있어야** 한다. 모든 (사실)/[전승] 카드에 사료 출처를 명시한다.
- **GDD 씨앗**: `09_codex.md` 모든 카드 "출처:" 줄, DECISION-C03(1차 출처 명시), 페어합의 "출처를 따라갈 수 있게".

> 5대 원칙 우선순위(충돌 시): **EP4(무해성) > EP2(라벨 무결성) > EP1(흐름) > EP3(메커닉=사료) > EP5(출처)**.
> 근거: 가족 친화 게임의 신뢰는 무해성이, 교육 신뢰는 라벨이 떠받친다. 흐름·고증·출처는 그 위에 쌓인다.

## 3. 코덱스 3층 노출 UX (L1/L2/L3) 확정 + 완성도 메타

> "노출 모델"은 같은 역사 지식을 **3단 깊이**로 점층 전달한다. 얕게 자주(L1) → 보상으로(L2) → 깊게 한 곳(L3).

### 3.1 L1 — 인게임 즉시 노출 (툴팁/배너/캡션)

| 요소 | 트리거 | 표시 | 후크 | 강제도 |
|---|---|---|---|---|
| 스테이지 도입 캡션 | 스테이지 시작 시 1회 | 화면 중앙 1줄 페이드(2초), 스킵 가능 | H1 | 비강제(자동 표시·자동 소멸) |
| 적 인트로 배너 | 신규 적 타입 **최초** 등장 웨이브 | 상단 배너 1줄([사실] 한 줄), 3초 자동 소멸 | H2 | 비강제 |
| 유닛/영웅 툴팁 | 유닛 패널 호버 / 선택 | 스탯 + `history_blurb` 사료 한 줄 | H3 | 사용자 호버 시에만 |
| 라벨 첫 노출 토스트 | [전승]/[픽션] 라벨 **게임 내 최초** 노출 시 | 하단 토스트(기존 `toast.first_legend_label`) | H6 | 자동 1회 |

원칙 EP1(흐름 보존): L1은 전부 **모달 금지**. 게임 일시정지 유발 안 함. 배너·캡션은 시간 경과로 자동 소멸.

### 3.2 L2 — 결과 카드 (클리어 보상)

| 항목 | 확정 사양 |
|---|---|
| 트리거 | 스테이지 클리어 결과 화면. 해당 스테이지 해금 카드를 카드 형태로 제시 |
| **앞면**(자동) | 카드 일러스트 + 제목 + 라벨 배지((사실)/[전승]/[픽션]) + "도감에 추가됨"(기존 `result.win.history_note`) |
| **본문**(L3 연결) | "도감에서 읽기" 버튼 → L3 상세로. 결과 화면에서 본문 전문 강제 노출 안 함 |
| 강제도 | **앞면만 자동 노출** — [DECISION-EDU-001]. 첫 클리어라도 본문 강제 1회 띄우지 않음(흐름 보존, EP1) |
| 신규 키 | `result.card.title`, `result.card.label_badge`, `result.card.read_in_codex`, `result.card.new_badge` (§6.4) |

### 3.3 L3 — 도감 (역사 노트 백과)

- 기존 화면 구조(`09_codex.md` §3 메인 그리드 + 카드 상세) 채택. 신규 화면 설계 불필요.
- 카드 상세 = 일러스트 + **라벨 배지** + 본문(`09_codex` 원천) + **출처**(EP5) + (있으면) **한문 원문 토글**(H9, §4·§6.1).
- 잠금 카드: 회색 자물쇠 + `codex.locked` 툴팁(기존).
- 탭: 역사노트/유닛/적/영웅(기존 `codex.tab.*`).

### 3.4 도감 완성도 메타 (15장 컬렉션)

| 항목 | 확정 사양 |

## 4. 라벨 전역 통일 규칙 + 3대 충돌지점 UX

### 4.1 라벨 3종 전역 규칙 (SSOT = `09_codex.md` §4 / `00_story_bible.md` §5)

| 라벨 | 표기(`08_ui_strings` 기존 키) | 적용 레이어 | 규칙 |
|---|---|---|---|
| (사실) | `codex.label.fact` = "(사실)" | L2 배지·L3 배지 | 1차 사료 근거. 카드엔 배지 생략 가능하나, **혼동 카드(전승과 인접)에는 명시 권장** |
| [전승] | `codex.label.legend` = "[전승]" | L1 토스트(최초 1회)·L2 배지·L3 배지 | 정사에 없는 후대 야사. **첫 노출 시 반드시 설명 토스트**(`toast.first_legend_label`) |
| [픽션] | `codex.label.fiction` = "[픽션]" | L1 토스트(최초 1회)·L2 배지·L3 배지 | 본 게임 창작. 첫 노출 시 설명(`toast.first_fiction_label`) |

**전역 규칙 R1~R5** (EP2 라벨 무결성 구현):
- **R1**: 화면에 노출되는 모든 역사 서술은 위 3종 중 하나로 분류 가능해야 한다(미분류 금지).

- **R3**: [전승]/[픽션]은 **각각 게임 내 최초 노출 1회** 설명 토스트를 띄운다(H6). 이후 절(scene) 내 반복은 배지만.
- **R4**: 라벨 분류가 `09_codex.md` §4 표와 불일치하면 `09_codex.md`가 이긴다(원천 우선).

## 6. dev-lead 인계용 데이터 스키마 요구

> 모든 신규 필드/키는 **예약(reservation)**. 실제 파일 반영은 후속 라운드. 본 절은 *요구 명세*다.
> 키 네이밍은 `08_ui_strings` §0.1 컨벤션(`<scene>.<component>.<role>`) 준수. 한국어 표시 텍스트는 Design Lead 확정(본 스펙은 키와 의미만).

### 6.1 신규 데이터 파일 `src/data/codex.json` (코덱스 카드 SSOT 데이터화)

현재 코덱스는 문서(`09_codex.md`)만 존재하고 게임 데이터 파일이 없다. L2/L3/완성도 메타 구현을 위해 카드 메타를 데이터화한다(**본문 텍스트는 ui_strings/story 원천에서 lookup, 여기엔 키·메타만**).

```jsonc
{
  "version": 1,
  "cards": [
    {
      "id": "codex_01",                       // 카드 식별자 (01~15)
      "title_key": "codex.card.01.title",      // 제목 (ui_strings lookup)
      "body_key": "codex.card.01.body",        // 본문 (09_codex 원천 → ui/story lookup)
      "source_key": "codex.card.01.source",    // 출처 줄
      "label": "fact",                          // enum: "fact" | "legend" | "fiction"  ★필수
      "unlock_condition": {                     // ★필수
        "type": "auto | stage_clear | stage_three_stars | true_ending",
        "stage": 1                              // type이 stage_* 일 때만
      },
      "illust": "codex_01",                     // 일러스트 키 (없으면 placeholder)
      "source_original": "三國史記 卷...",       // 옵션(H9): 한문 원문 (사실 라벨 카드만 권장)
      "source_reading": "삼국사기 권...",         // 옵션(H9): 독음/서지
      "source_translation": "..."               // 옵션(H9): 현대어 번역(짧게)
    }
  ]
}
```

- `label`: **enum 3값** `fact`/`legend`/`fiction`. (사실+게임각색)은 `fact` + 본문 각색 고지(R5).
- `unlock_condition`: `09_codex` §1 해금표를 그대로 데이터화(자동/스테이지클리어/별3개/진엔딩).
- `source_original`/`reading`/`translation`: **옵션**. [DECISION-EDU-003]에 따라 **(사실) 라벨 카드 우선** 채움.

## 7. 미결 4건 — 자율 결정 [DECISION-EDU-*]

> 사용자가 풀 스펙 + 자율 진행을 승인. 각 결정은 권고 기본값을 채택하되 근거를 명시한다.

### [DECISION-EDU-001] L2 결과 카드 강제도 = **앞면만 자동 노출**
- **결정**: 클리어 결과 화면에서 카드 **앞면(일러스트+제목+라벨 배지+NEW)만 자동 노출**. 첫 클리어라도 본문 전문을 강제로 띄우지 않는다. 본문은 "도감에서 읽기"로 자발적 진입.
- **근거**: EP1(흐름 보존) 최우선. `02_concept_brief` §10 페어합의("[역사 노트] 너무 띄우면 흐름 끊김 → 보상으로"). 부모-자녀 페어 세션(페르소나 A+B)은 짧은 흐름이 핵심. 본문 강제는 클리어의 성취 리듬을 끊는다.
- **대안 기각**: "첫 클리어 한정 본문 1회 강제"는 교육 도달률을 약간 높이나, LO1/LO2는 H1·H7로 이미 인게임 노출되므로 본문 강제의 한계효용이 흐름 비용보다 작다.

### [DECISION-EDU-002] 진엔딩 4문항 퀴즈 = **채택하되 스킵 가능 + 보상형(부드럽게)**
- **결정**: 진엔딩(5스테이지 전부 별3개)에서 LO1~LO4 복습 4문항 제공. **건너뛰기 항상 가능**, 오답이 진행/엔딩을 막지 않음. 정답 시 카드15 강조·칭호 등 **능력치 무관 보상**만. 오답엔 격려 1줄.
- **근거**: 가족 친화 톤(EP4)에서 "시험"은 거부감 리스크 → 강제 평가가 아닌 **선택형 복습 놀이**로 톤을 낮춘다. 진엔딩 도달자는 이미 몰입도 높은 학습자라 보상형이 자연스럽다. 페르소나 A(아이)에게 비난 없는 퀴즈는 긍정적.
- **대안 기각**: "미채택"은 LO 복습 기회를 버린다. "필수 통과형"은 EP4 위반.

### [DECISION-EDU-003] 한문 원문 노출 범위 = **(사실) 라벨 카드 우선** (15장 전체 아님)
- **결정**: `source_original`/`reading`/`translation`은 **(사실) 라벨 카드(약 10장: 01·02·03·04·05·06·09·10·11·12 + 활 카드08)부터** 우선 채운다. [전승]/[픽션] 카드는 원문이 야사·창작이라 한문 원문이 부적절하거나 무의미하므로 제외. 옵션 필드이므로 미입력 카드는 토글 자체를 숨김.
- **근거**: EP5(출처 다리)는 (사실)에서 가장 가치가 크다. 콘텐츠 공수(한문 교열·독음·번역) 대비 효과 집중. [전승] 카드13/14에 한문 원문을 달면 야사를 사료처럼 보이게 해 EP2 위반 위험.
- **대안 기각**: "15장 전체"는 공수 과다 + [전승]/[픽션]에 원문 부적합.

### [DECISION-EDU-004] 로컬 학습통계 = **완전 오프라인·외부 전송 없음 + 설정에 1줄 고지**
- **결정**: 도감 완성도/퀴즈 결과 등 학습통계는 **로컬 저장 슬롯에만** 기록, **외부 전송·수집 일절 없음**. 별도 부모 동의 절차 없이, 설정 메뉴에 **고지 1줄**만 추가(신규 키 `settings.privacy.local_only` = "이 게임은 모든 기록을 이 컴퓨터에만 저장하며, 외부로 전송하지 않습니다.").
- **근거**: `02_concept_brief` §5 "오프라인/무과금" 정체성. 외부 전송이 없으므로 능동적 부모 동의(opt-in) 절차는 과잉. 다만 학부모 페르소나(B)의 신뢰를 위해 **투명 고지**는 제공(EP4 무해성의 신뢰 차원).
- **대안 기각**: "부모 동의 모달 강제"는 오프라인 게임에 불필요한 마찰. "고지 전무"는 학부모 신뢰 측면에서 아쉬움.
