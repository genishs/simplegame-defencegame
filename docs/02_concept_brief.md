## 2. 핵심 재미 (Core Loop)

```
[자원 채집] → [성벽·궁수·영웅 배치] → [당군 공격 방어] → [성벽 복구] → [다음 웨이브] → [스테이지 클리어]
```

### 세 가지 재미 축
1. **역사 재현의 쾌감** — 교과서에서 본 사건이 내 손에서 펼쳐진다. (토산 붕괴, 주필산 매복 등)
2. **자원 운용의 긴장감** — 곡식으로 병사 충원 vs 성벽 복구. 트레이드오프.
3. **영웅 컨트롤** — 양만춘 스킬 4종을 적시에 발동 (장궁 집중 사격, 사기 진작, 야간 기습, 토산 붕괴).

## 3. 타깃 페르소나

### 페르소나 A: "역사 좋아하는 초등 고학년 — 도윤이(11세)"
- 학교 사회 시간에 고구려를 배웠고, 영화 『안시성』(2018)을 부모와 봤음.
- 게임은 좋아하지만 부모가 폭력적인 게임을 못 하게 함.
- 친구들과 한국사 퀴즈를 가끔 함.
- **니즈**: "역사 게임인데 재미있고, 부모님이 허락해 줄만한 것."
- **유입 경로**: 부모님이 다운로드, 함께 플레이.

### 페르소나 B: "교육에 관심 많은 학부모 — 지은(38세)"
- 자녀 사교육 줄이고 자기주도학습 콘텐츠 찾는 중.
- 스마트폰 게임의 과금·폭력성에 거부감.
- 한국사 콘텐츠는 무조건 환영.
- **니즈**: "아이와 함께 즐기며 한국사도 배울 수 있는 PC 게임."
- **유입 경로**: 맘카페, 학부모 커뮤니티, 교육 유튜브.

### 페르소나 C: "한국사 마니아 성인 — 민호(34세)"
- 한국사능력검정 1급. 인디게임 좋아함.
- 영화 『안시성』, 『명량』, 드라마 『연개소문』 다 봤음.
- **니즈**: "고증이 단단한 한국사 게임. 진지하되 무겁지 않은 톤."
- **유입 경로**: Steam, 인디게임 커뮤니티, X(트위터).

> **DECISION**: 1차 페르소나는 A+B(부모-자녀 페어). C는 2차. UI는 한자·전문용어에 한글 병기 + 마우스 오버 시 설명 툴팁 제공.

## 5. 가치 명제 (Value Proposition)

> **"교육적 + 재미있는 한국사 디펜스 — 아이와 부모가 함께, 88일을 버티며 자랑스러운 우리 역사를 손으로 체험한다."**

### 차별화 포인트
1. **사료 기반 고증** — 삼국사기·자치통감에 근거한 사건만 핵심으로. 야사는 [전설] 라벨.
2. **가족 친화 톤** — 잔혹 묘사 일체 배제. 둥글둥글 캐릭터.
3. **교육 후크** — 스테이지마다 "[역사 노트]" 카드 해금. 사료 원문 한 줄 + 현대어 풀이.
4. **짧은 세션** — 10~15분 단위. 부모-자녀 함께 부담 없이.
5. **오프라인 / 무과금** — Python tkinter, 가벼운 데스크톱 실행.

## 6. 5스테이지 큰 그림

| # | 스테이지명 | 역사 사건 | 핵심 메커닉 (한 줄) |
|---|---|---|---|
| **1** | **전쟁의 그림자** | 645년 4~6월 요동 방어선 함락 (개모·요동·백암성) | 튜토리얼 — 궁수 배치, 자원 채집 학습 |
| **2** | **들판의 함정** (주필산) | 6월 하순 주필산 전투, 고연수·고혜진 15만 군 매복 패배 | 위장 후퇴에 속지 않기 — "추격 충동을 참아야 클리어" |
| **3** | **사방의 공성무기** | 7~8월 당군의 충차·운제·포차 동시 공격 | 적 유닛 다양화 — 상성 카운터 학습, 양만춘 1차 스킬 해금 |
| **4** | **버티는 자가 이긴다** | 8~9월 장기 농성, 성벽 복구·자원 압박 | 자원 운용 심화 — 곡식/화살 트레이드오프, 야간 웨이브 |
| **5** | **토산 결전** (최종) | 9월 토산 60일 구축 → 붕괴 → 고구려군 점령 → 당군 철수 | 보스 메커닉 — 토산 게이지 vs 당군 사기/추위 게이지, 양만춘 궁극기 "토산 붕괴" |

> **DECISION**: 스테이지 1은 짧게(5분), 2~4는 10~12분, 5는 15분. 난이도는 1→5로 완만한 상승, 5에서 급상승.

## 7. 영웅 — 양만춘 (전승)

| 항목 | 내용 |
|---|---|
| 이름 표기 | 양만춘 (梁萬春 / 楊萬春) — *전승* |
| 무장 | 장궁(長弓), 찰갑(札甲) |
| 디자인 | 둥글둥글 SD, 갈색 갑옷, 붉은 어깨끈, 짧은 수염 |
| 기본 공격 | 장궁 사격 — 단일 적 원거리 |
| 패시브 | **삼익촉(三翼鏃)** — 명중 시 인접 적에게 미세 광역 (3갈래 화살) |
| 스킬 1 (STG3 해금) | **집중 사격** — 단일 적 폭딜 |
| 스킬 2 (STG4 해금) | **사기 진작** — 아군 공격력 +30%, 10초 |
| 스킬 3 (STG4 해금) | **야간 기습** — 적 진영 사기 -20%, 일시 정지 |
| 스킬 4 (STG5 해금) | **토산 붕괴** — 적 토산에 큰 대미지 + 적군 일시 이동 불가 |

> 사료 노트(게임 내 표기 예정): *"안시성주의 이름은 정사(삼국사기·자치통감)에는 전하지 않습니다. '양만춘'은 16세기 이후 전승으로 알려진 이름입니다."*

## 8. 자원 시스템

| 자원 | 획득 | 사용처 |
|---|---|---|

## 10. UX 원칙 (가족 친화)

- 마우스 클릭/드래그 위주, 단축키 보조.
- 한 화면 안에 모든 정보 표시 (스크롤 최소화).
- "[역사 노트]" 버튼 항시 노출 — 클릭 시 사료 원문/풀이 카드.
- 실패 시 비난 톤 X. "다시 도전해 보세요. 양만춘도 88일을 버텼습니다." 같은 격려 메시지.
- 한자·전문용어는 한글 병기 + 마우스오버 툴팁.

## 부록. 페어 토의 로그 (요약)

- **PM**: "제목 후보 — 『안시성』은 영화랑 겹쳐서 안 됨. 『88일의 약속』, 『양만춘의 활』, 『요동의 별』 중 골라보자."
- **팀원**: "『안시성: 88일의 약속』 좋다. '안시성'은 키워드로 살리고 부제로 차별화. SEO에도 유리."
- **PM**: "동의. 가제로 확정."
- **팀원**: "5스테이지가 모두 안시성 한 곳이면 단조롭지 않을까? 스테이지 1을 다른 성으로 두면?"
- **PM**: "좋은 의견. 스테이지 1 '전쟁의 그림자'는 작은 변경 초소. 시네마틱으로 요동성 함락을 보여주고, 안시성으로 양만춘이 부임하는 흐름. 스테이지 2는 야전(주필산), 3~5는 안시성."
- **팀원**: "양만춘 스킬 해금 타이밍. 1, 2에서 너무 약하면 재미없을 것 같음."
- **PM**: "기본 공격 + 패시브는 처음부터. 액티브 스킬은 3, 4, 5에서 점진 해금. 학습 곡선."
- **팀원**: "교육 후크 [역사 노트] 너무 띄우면 게임 흐름 끊김. 스테이지 끝나고 보상으로 주는 게 나음."
- **PM**: "스테이지 클리어 보상으로 [역사 노트] 카드 1장 + 컬렉션 화면 따로. 모으는 재미."
- **팀원**: "최종 확정."

— 토의 종료. Phase 2 (게임 디자인 문서)로 인계.
