## 0. 페어 토의 메모 (요약)

- **리더**: "안시성 본전은 절정에 둬야 하니까 1~3스테이지는 인트로 + 변방 성, 4스테이지가 안시성 전초, 5스테이지가 본전 + 토산이다."
- **팀원**: "동의. 다만 1스테이지는 너무 쉬워야 합니다. tkinter Canvas 성능 한계상 동시 60유닛 넘기면 위험하니까요."
- **리더**: "그리고 잔혹 묘사 금지. 패배 연출은 병사가 회색조로 페이드아웃하고 슬픈 가야금 한 음."
- **팀원**: "메타 진행은 미니멀 메타로 갑니다. 병영 영구 업그레이드 트리 1개 + 스테이지 별 보상."

### DECISION 라벨 (이 GDD에서 확정한 핵심 결정)

- **DECISION-01**: 5스테이지 = 요동성(인트로) → 백암성 → 개모성(보조 라인) → 안시성 외곽 → 안시성 본전(토산)
- **DECISION-02**: 자원 3종 — 곡식(빌드 자원), 인구(소집 가능 병사 수), 화살(전투 중 충전 소모)
- **DECISION-03**: 영구 메타는 "병영 강화 트리" 1개로 한정 (5단계). 그 외는 인게임 일회성
- **DECISION-04**: 아트 = 2~3등신 둥근 캐릭터 + 64px 타일, 색상은 고구려 청·황토·녹 / 당군 적·흑·금
- **DECISION-05**: tkinter Canvas로 구현 가능한 범위 — 파티클 시스템 X, 셰이더 X, 스프라이트 단순 이동/페이드만
- **DECISION-06**: 화약 무기 등 시대착오 금지. 폭발 효과는 "투석기 돌탄"만 허용
- **DECISION-07**: 동시 화면 유닛 상한 = 60체 (성능 안전 마진)

## 1. 게임 개요

### 1.1 한 단락 비전

> *645년 가을, 당 태종의 30만 대군이 요동을 휩쓸고 안시성 성문 앞까지 다다랐다. 양만춘과 고구려 백성들은 작은 산성 하나로 88일을 버텨낸다.* "안시성 645"는 그 88일을 다섯 챕터의 타워디펜스로 압축한 게임이다. 둥글둥글한 캐릭터와 따뜻한 한국 전통 색감 속에서, 플레이어는 양만춘을 도와 곡식을 모으고, 궁수와 창병을 성벽에 배치하며, 적의 토산(土山)이 무너지는 그 결정적 순간을 함께 만든다.

### 1.2 핵심 게임 루프

```
[15초 루프] — 마이크로
  곡식 +1 ─▶ 유닛 1체 배치 ─▶ 적 척후 처리 ─▶ 다시 곡식 +1
  (체감 단위: 한 번의 의사결정)

[1분 루프] — 미드
  웨이브 1차 도착 ─▶ 화살/스킬 소모 ─▶ 웨이브 격퇴 ─▶
  자원 정산(곡식·화살 회복) ─▶ 다음 웨이브 준비(배치 재정렬)

[10분 루프] — 매크로
  스테이지 시작 ─▶ 도입 컷씬(역사 한 줄) ─▶ 3~5 웨이브 ─▶
  보스/특수이벤트 ─▶ 클리어 ─▶ 별 평가 ─▶ 병영 메타 업그레이드 1포인트
```

### 1.3 승리/패배 조건

| 구분 | 조건 |
|---|---|
| **승리** | 해당 스테이지의 모든 웨이브 격퇴 또는 보스 격파 |
| **패배** | 성문(코어) HP가 0이 됨 / 또는 양만춘 사망(스테이지 5만 적용) |
| **별 3개** | 1. 클리어 / 2. 성문 HP 70% 이상 유지 / 3. 특별 목표(스테이지별 다름) |

### 2.1 스테이지 총괄 표

| # | 스테이지 | 역사 사건 | 주요 메커닉 해금 | 보스/이벤트 | 플레이타임 |

| 2 | 백암성의 항복 | 백암성 평화 함락 일화 | 곡식 생산소 건설 | (없음) 평화 설득 분기 | 7~9분 |

### 2.2 스테이지 1 — 요동성의 첫눈

#### 역사 컨텍스트
- 요동성은 안시성보다 먼저 함락된 큰 성. 당군의 화공·운제(雲梯)에 무너졌다.
- 게임에서는 **함락 직전의 짧은 방어전**으로 다룬다. 플레이어가 "여기는 함락된다, 안시성으로 후퇴하라"는 명령을 받는 인트로.

#### 맵 컨셉
```
       N (북) — 당군 본진 (적 스폰)
       │
       ▼ (적 진군 방향)
   ┌───────────────┐
   │  ◇ ◇ ◇ ◇ ◇    │  ← 평지 (당군 보병 라인)
   │ ─────────────  │
   │ ▣ ▣ ▣ ▣ ▣ ▣  │  ← 1단 성벽 (배치 슬롯 5칸)
   │ ─────────────  │
   │ ★ 성문 (코어)  │  ← 방어 목표
   └───────────────┘
       S (남) — 후퇴 통로
```
- **지형**: 평지 + 단일 성벽. 강·산 없음(튜토리얼 단순화)
- **진입 방향**: 북 → 남, 단일 경로

#### 적 구성 (총 5 웨이브)

| 웨이브 | 구성 | 비고 |
|---|---|---|
| W1 | 보병 ×4 | 튜토리얼 |
| W2 | 보병 ×6 + 궁수 ×2 | 원거리 도입 |
| W3 | 보병 ×8 | 첫 압박 |
| W4 | 보병 ×6 + 궁수 ×4 | 혼합 |
| W5 (보스) | 척후대장 ×1 + 보병 ×4 | 보스 도입 |

#### 해금 메커닉
- [O] 고구려 궁수 (기본)
- [O] 고구려 창병 (기본)
- [O] 곡식 자동생성 (초당 1)
- [O] 화살 무한 (튜토리얼 한정)

#### 보스: 당군 척후대장 "리우(劉)"
- HP 200, 이동속도 보통, 근접 공격
- 특수: 처치 시 보병 ×2 추가 스폰 1회

#### 별 3개 조건
1. 스테이지 클리어
2. 성문 HP 70% 이상 유지
3. **사망 아군 3체 이하**

### 2.3 스테이지 2 — 백암성의 항복

#### 역사 컨텍스트
- 백암성주 손대음이 항복을 고민하는 일화. 당 태종은 항복한 성민을 보호함.
- 게임에서는 **평화 분기**: 플레이어가 일정 조건 충족 시 "백성을 살린다"는 별 보상 가능.

#### 맵 컨셉
```
   N — 당군 (대규모)
   │
   ▼
  ┌──────────────────┐
  │ 〰 〰 강 〰 〰    │  ← 강 (적 도하 속도 감소)
  │ ▣ ▣ 다리 ▣ ▣    │
  │ ─────────────    │
  │ ▣ ▣ ▣ ▣ ▣ ▣ ▣  │  ← 성벽
  │ ★ 성문            │
  │ 🌾 곡식밭 (밖)     │  ← 새 메커닉
  └──────────────────┘
```
- **지형**: 강 + 다리 (병목)
- **진입 방향**: 북 → 다리 → 남

#### 적 구성 (총 6 웨이브)

| 웨이브 | 구성 |
|---|---|
| W1 | 보병 ×6 |
| W2 | 보병 ×8 + 궁수 ×3 |
| W3 | 중장보병 ×2 + 보병 ×4 |
| W4 | 궁수 ×6 + 보병 ×4 |
| W5 | 보병 ×10 |
| W6 | 혼합 ×12 (러시) |

#### 해금 메커닉
- [O] **곡식 생산소** (성벽 밖 슬롯에 건설, 곡식 +0.5/s. 단 적의 약탈 표적)
- [O] **유닛 수동 회수** (배치 취소 50% 환불)

#### 특수 이벤트: 평화 설득
- 4웨이브 종료 시 "백암성주 항복" 이벤트 발생
- 플레이어 선택지:
  - **(A) 항복 수락**: 잔여 웨이브 스킵, 별 3개 자동 획득, 곡식 보상 -50%
  - **(B) 끝까지 싸움**: 5·6웨이브 진행, 별 3개는 일반 조건, 곡식 보상 100%
- 어느 쪽이든 다음 스테이지 진입 가능. (역사 정합: 항복도 실제 있었던 일)

#### 별 3개 조건 (B 선택 시)
1. 클리어
2. 성문 HP 70% 이상
3. **곡식밭 2개 이상 파괴되지 않음**

### 2.4 스테이지 3 — 개모성의 횃불

#### 역사 컨텍스트
- 개모성도 645년 당의 공격 대상. 게임에서는 야간 방어전으로 각색.
- 당군의 야습 + 횃불로 시야 확보가 메인 테마.

#### 맵 컨셉
```
   N — 당군 야습대 (시야 짧음)
   │
   ▼
  ┌─────────────────────┐
  │ ▲▲ 산 ▲▲ (좌측 차단) │
  │   ─────────         │  ← 좁은 협곡 통로
  │   ▣ ▣ ▣ ▣ ▣        │
  │ 🔥 🔥 🔥 🔥 🔥      │  ← 횃불 슬롯 (시야 확보)
  │   ★ 성문            │
  └─────────────────────┘
```
- **지형**: 산악 협곡, 야간 (화면 어둡게, 횃불 주변만 밝음)
- **진입 방향**: 북 → 협곡 → 남

#### 적 구성 (총 6 웨이브, 야간 보너스로 적 회피 +10%)

| 웨이브 | 구성 |
|---|---|
| W1 | 척후 ×6 (은신, 횃불 사거리 내에서만 식별) |
| W2 | 보병 ×8 + 척후 ×4 |
| W3 | 궁수 ×6 + 보병 ×6 |
| W4 | 중장보병 ×3 + 보병 ×6 |
| W5 | 척후 ×10 (대규모 침투) |
| W6 (보스) | 야습 부대장 + 보병 ×6 |

#### 해금 메커닉
- [O] **장창병** (전열, 기병·중장보병에 보너스 데미지)
- [O] **횃불 시스템** (곡식 5/개, 시야 반경 +120px, 화면 어두움 해소)
- [O] **야간 시야** (배치된 유닛 시야 반경 -30%)

#### 보스: 야습 부대장 "장(張)"
- HP 350, 빠름, 처음에는 은신
- 횃불 사거리 내 들어와야 공격 가능

#### 별 3개 조건
1. 클리어
2. 성문 HP 70% 이상
3. **횃불 6개 이상 동시에 점등 시점 1회 이상**

### 2.5 스테이지 4 — 안시성 외곽

#### 역사 컨텍스트
- 당군이 안시성 도착, 외성을 두고 첫 충돌. 이세적(李世勣)·이도종 등 명장이 등장.
- 게임에서는 **공성병기의 본격 등장** + 첫 출격(기병) 메커닉.

#### 맵 컨셉
```
   N — 당 본진 (이세적)
   │
   ▼  (3 갈래 경로)
  ┌──────────────────────────┐
  │  ↘    ↓    ↙             │
  │ ────────────────────────  │
  │ ▣ 외성벽 ▣ ▣ ▣ ▣ ▣      │
  │ ─────────────────         │
  │ ▣ ▣ 본성벽 ▣ ▣ ▣ ▣      │  ← 2단 성벽
  │ ─────  ─────              │
  │ 🏇 출격구 (좌) 🏇 (우)    │  ← 기병 출격
  │ ★ 본 성문                 │
  └──────────────────────────┘
```
- **지형**: 2단 성벽(외성+본성), 3갈래 진입로
- **진입 방향**: 북 → 3갈래 → 외성 → 본성

#### 적 구성 (총 7 웨이브)

| 웨이브 | 구성 |
|---|---|
| W1 | 보병 ×10 |
| W2 | 궁수 ×8 + 보병 ×6 |
| W3 | **공성탑 ×1** + 보병 ×8 |
| W4 | 중장보병 ×5 + 궁수 ×4 |
| W5 | **충차 ×2** + 보병 ×8 |
| W6 | 기병 ×6 + 궁수 ×6 |
| W7 (보스) | **이세적의 정예 충차** + 중장보병 ×6 |

#### 해금 메커닉
- [O] **투석기 (아군)**: 곡식 25, 광역 데미지, 사거리 길고 재장전 느림
- [O] **기병 출격** (전투 외 자원: "사기" 게이지 100% 충전 시 좌/우 출격구에서 적 측면 강타)
- [O] **2단 성벽**: 외성 함락 시 본성으로 후퇴 가능 (외성 슬롯의 유닛 50% 회수)

#### 보스: 이세적의 정예 충차
- HP 1200, 매우 느림, 성문에만 데미지
- 측면에 약점(빨간 점) — 기병 출격이나 투석기로 노릴 것

#### 별 3개 조건
1. 클리어
2. 본성 성문 HP 50% 이상 (외성은 함락 허용)
3. **기병 출격 2회 이상 성공**

### 2.6 스테이지 5 — 안시성 토산 (최종)

#### 역사 컨텍스트
- 당군이 60일간 토산(흙산)을 쌓아 성벽 높이까지 올렸으나, 토산이 무너지며 오히려 고구려군이 점령. 88일째 당 태종 후퇴.
- 게임 최후 스테이지로, 88일 압축 + 토산 메커닉이 핵심.

#### 맵 컨셉
```
   N — 당 본진 (당 태종)
   │
   ▼
  ┌─────────────────────────────────┐
  │   ⛰ 토산 (성장 중) ⛰            │  ← 시간이 지나면 높아짐
  │   ↓ (높아질수록 적 직접 성벽 진입) │
  │ ════════════════════════         │
  │ ▣ ▣ ▣ 본성벽 ▣ ▣ ▣ ▣          │
  │ ─────────────────────            │
  │ 🏇 출격구  ★ 양만춘 본진  🏇    │
  │ ★ 성문                            │
  └─────────────────────────────────┘
```
- **지형**: 평지 + 점점 자라는 토산 (좌·우 2지점)
- **진입 방향**: 북 → 토산 정상 → 성벽 직진입 (후반) / 북 → 정문 (전반)

#### 적 구성 (총 10 웨이브 + 페이즈 2개)

##### Phase 1 (W1~W6): 정면 공성
| 웨이브 | 구성 |
|---|---|
| W1 | 보병 ×12 |
| W2 | 궁수 ×10 + 보병 ×6 |
| W3 | 충차 ×1 + 보병 ×10 |

## 7. 레벨업 / 메타 진행

### 7.1 미니멀 메타 — "병영 강화 트리"

- 스테이지 클리어 시 별 1개당 **명성 포인트 +1**
- 총 명성으로 병영 강화 트리(5단계) 해금
- 한 번 해금하면 영구 적용

#### 병영 강화 트리

```
[Tier 1] 단단한 갑옷  (명성 3)
  └ 모든 아군 HP +10%
       │
       ▼
[Tier 2] 잘 벼린 화살촉 (명성 5)
  └ 궁수/양만춘 공격력 +10%
       │
       ▼
[Tier 3] 풍년 (명성 8)
  └ 곡식 시작 +30, 자동생성 +0.2/s
       │
       ▼
[Tier 4] 군기 (명성 12)
  └ 인구 상한 +2, 사망 회복 속도 2배
       │
       ▼
[Tier 5] 안시의 정신 (명성 18) ★ 최종
  └ 양만춘 궁극기 쿨다운 -30s, 부활 쿨다운 -20s
```

- 최대 명성: 5 스테이지 × 별 3개 = **15** (스테이지 1 1회 클리어 시) + 재플레이 가능
- DECISION: 별 = 명성. 재플레이로 추가 별 획득은 **불가** (한 스테이지 최대 3 명성). 재플레이는 자유연습용.

### 7.2 인게임 일회성 강화

- 스테이지 중 웨이브 사이 휴식 시, 2개 카드 중 1개 선택 (랜덤 풀)
  - 예) "이번 스테이지만 궁수 공격속도 +15%"
  - 예) "곡식 +30"
  - 예) "다음 웨이브 적 5% 감소"
- 1 스테이지 = 2~3회 선택 기회

### 9.2 캐릭터 스타일 가이드

- **등신**: 2~3등신, 머리:몸 = 1:1.5

- **윤곽선**: 1~2px의 어두운 갈색 외곽선 (가독성)
- **그림자**: 발 밑 타원형 단순 그림자 (반투명 30%)
- **애니메이션**: 4프레임 이내의 매우 단순한 루프 (걸음 2프레임, 공격 2~3프레임)
  - tkinter Canvas 성능 고려, 이미지 스왑 기반

### 9.3 환경 스타일

- **타일 크기**: 64×64px (FHD 기준)
- **맵 격자**: 30×17 타일 (1920÷64=30, 1080÷64≈17) 중 게임 영역은 20×11
- **타일 종류**:
  - 평지 (베이지)
  - 풀밭 (녹)
  - 성벽 (회색, 1단/2단)
  - 강 (청, 애니메이션은 색 점멸 2프레임)
  - 다리 (갈색)
  - 산 (짙은 녹, 통행 불가)
  - 토산 (황토, 성장 단계 3종)
  - 길 (어두운 토양)

### 9.4 폰트

- **본문**: 맑은 고딕 (Windows 기본) / Noto Sans KR (대체)
- **타이틀/강조**: 본고딕 Heavy / 함초롬돋움 / 한국 전통 느낌은 "나눔명조" 사용
- 코드 내 폰트 폴백 순서: `Malgun Gothic → Noto Sans KR → AppleGothic → 기본`
- 크기 (FHD 기준):
  - 본문 16~18px
  - 라벨 14px
  - 강조 24~32px
  - 타이틀 48~64px

### 9.5 이펙트 가이드 (tkinter Canvas 가능 범위)

| 이펙트 | 구현 방식 |
|---|---|
| 공격 히트 | 작은 노란 원, 100ms 후 제거 |
| 화살 비행 | 검은 선 (line) 1~2px, 위치 보간 |
| 폭발(투석) | 빨간 원 → 노란 원 → 회색 원 (3단계 페이드) |
| 체력바 | 머리 위 빨간/녹 사각형 |
| 처치 연출 | 회색조 + 알파 페이드 (300ms) |
| 스킬 이펙트 | 단순한 도형(원·다이아) + 색 점멸 |

## 12. 접근성 / UX

### 12.1 필수 접근성

| 항목 | 사양 |
|---|---|
| **일시정지** | 스페이스 / 게임 메뉴 / 자동 (앱 비활성) |
| **속도** | 1× / 2× 토글 (F 키), 0.5× 옵션은 설정 메뉴 |
| **키보드 단축** | 1~5(유닛), Q/W/E/R(스킬), M(직접조작), Tab(미니맵) |
| **색약 모드** | ON/OFF. ON 시 아군=청, 적=주황+패턴(줄무늬), HP바에 숫자 표시 |
| **자막** | 컷씬·보이스 모두 한글 자막 항상 ON |
| **글씨 크기** | 100% / 125% / 150% 3단계 |
| **마우스만 모드** | 모든 행동 마우스로 가능 (키보드 필수 X) |

### 12.2 UX 원칙

- **첫 30초 안에 첫 유닛 배치**: 스테이지 1 튜토리얼은 풍선 도움말로 강제 시연
- **에러는 부드럽게**: 자원 부족 시 빨간 점멸 + "곡식이 부족합니다" 한 줄, 짜증 유발 없음
- **실패는 격려**: 패배 화면에 "다시 도전" 큰 버튼, 죽은 병사 수 등 자랑 가능한 통계 1줄
- **세이브**: 자동 세이브 (스테이지 클리어 시점). 수동 세이브 슬롯 3개

### 12.3 가족 친화 가이드

- 피·잔혹 묘사 절대 금지
- "죽음" 단어 최소화 — "쓰러짐", "후퇴", "잠듦" 사용
- 적도 인간적으로 — 처치 후 회색 페이드, 잔재 X
- 보스의 후퇴 연출은 평화적으로 (예: 당 태종은 "북으로 돌아가다")
