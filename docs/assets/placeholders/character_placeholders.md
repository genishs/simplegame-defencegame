## 1. 공통 placeholder 규격

### 1.1 사이즈

| 사용처 | 사이즈 (Phase 4 PNG) | Phase 3 ASCII 시안 |
| --- | --- | --- |
| 컷씬 풀패널 (인트로 P5~P9, 엔딩 E4/E5/E7) | 1920×820 PNG-24 | 본 문서 §3 의 글리프 + 색 가이드만 (실제 ASCII는 64×64 베이스로 시연) |
| 영웅 portrait (양만춘) | 128×128 PNG-32 | 64×64 ASCII |
| 코덱스 영웅 탭 카드 (5명) | 64×64 PNG-32 + 본문 텍스트 | 64×64 ASCII |
| HUD HRO-02 (양만춘 초상화) | 80×100 (와이어프레임 §8.6.2) | 양만춘 placeholder 의 축약 |

### 1.2 구성 요소

각 placeholder 는 다음 3요소로 구성:

1. **한자 캘리그래피 글리프 1자** — 캐릭터를 대표하는 성/이름의 1자. 굵은 SemiBold 또는 Black 두께.
2. **배경 그라데이션 또는 단색** — 캐릭터 시그니처 색 (스토리 바이블 §2 외형 키워드 기반).
3. **테두리 / 라벨 칩** — 픽션은 `[픽션]` (DECISION-D-P3-002), 양만춘은 `[전승]`, 라벨 칩 색은 와이어프레임 §12.3 라벨 칩 스타일 표를 따른다.

- 픽션 4명 (모용손, 향이, 리우, 장): `[픽션]` — 황토 (`#C8954D`) 배경 + 흰 글씨 (`#F5F0E6`) (와이어프레임 §12.3, DECISION-D-P3-002 에 의해 `[픽션]` 황금 `#D4A84A` 검은 글씨에서 격상 후 스타일).

라벨 칩 사이즈: 본 placeholder 의 좌하단 모서리 (안쪽 8px 패딩) 에 32×24 (와이어프레임 §6.1 9-슬라이스 `ui_chip_label`).
