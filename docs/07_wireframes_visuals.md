## 0. 본 문서의 사용법 (Reader's Guide)

본 문서는 개발 파트(클라이언트 엔지니어 A·B)와 아트 파트가 동시에 참조한다.

- **개발자에게**: 각 컴포넌트의 `pos`, `size`, `scale_axis`는 그대로 `src/ui/*.py`와 `src/scenes/*.py` 구현 좌표가 된다. 베이스 좌표 float 그대로 받아 `scaler.to_screen(x, y)`로 변환한다.
- **아트에게**: 컬러 팔레트(§14)와 아이콘 그리드(§16)는 PNG 추출 직전 마지막 합의이다. 추가는 PR로 가능, 변경은 디자인 리더 사인오프 필요.
- **기획에게**: 모든 표시 텍스트는 `docs/story/08_ui_strings.md`의 KEY를 인용한다. 새 문자열이 필요하면 본 문서가 아닌 08_ui_strings.md에 추가하고 KEY만 본 문서에 인용한다.

### 표기 약속

- **베이스 좌표**: 1920×1080 기준 float. `pos=(x, y)`는 좌상단 기준. `size=(w, h)`.
- **3축 스케일 거동** (DECISION-3.1 of 04):
  - `coords`: 좌표만 비례. `canvas.scale("all", 0, 0, s, s)`로 일괄 처리.
  - `images`: 사이즈별 재캐시 후 `itemconfigure(image=...)` 교체.
  - `fonts`: 별도 재설정 (`scaler.font_pt(base_pt)`).
- 각 컴포넌트는 셋 중 하나 이상을 따르도록 명시.
- **KEY**: `docs/story/08_ui_strings.md` (SSOT, DECISION-D-P3-001) 의 식별자. 게임 코드는 절대 raw 문자열 하드코딩 금지. 본 문서의 컴포넌트 표 "KEY" 열에 텍스트가 아닌 KEY 만 인용.
- **[픽션]**: PM OPEN-1 종결 (DECISION-Q-001, 2026-05-19) — 모용손, 향이, 리우, 장 등 픽션 캐릭터는 사용자 승인 완료. 등장 시 `[픽션]` 라벨 부착 (Phase 3.4 라벨 격상 — DECISION-D-P3-002, 본 문서 §1.5).

### 15.3 스케일 규칙

3축 스케일링(DECISION-D-004) 중 fonts 축은 별도 재설정 필요:

```python
def font_pt(base_pt: int, scale: float, user_size: float = 1.0) -> int:
    # 베이스 pt에 윈도우 스케일과 사용자 글씨 크기 배율 적용.
    return max(8, int(base_pt * scale * user_size))
```

- `scale`: 윈도우 스케일러 (예: 1280px 윈도우면 0.667)
- `user_size`: 설정 메뉴의 글씨 크기 (100%=1.0, 125%=1.25, 150%=1.5)
- 최소 8pt 보장 (시인성)

### 15.4 줄 간격 / 자간

- **줄 간격**: 폰트 크기의 **1.4배** (가독성). 코덱스 본문 18pt → 줄 간격 25.2px.
- **자간**: 한글은 자간 0 (기본). 한자 표기 시 괄호 앞뒤 0.5em 여백.
- **단락 간격**: 본문 18pt 기준 단락 사이 16px.

### 15.5 한자 표기 규칙 (DECISION-D-011)

## 20. 인트로·엔딩 컷씬 패널 배치 종합

인트로(10패널) + 엔딩(8패널) = 총 18패널. 모든 패널은 **정지화 + 텍스트 페이드** 구조이며 풀 애니메이션 없음(DECISION-D-010).

### 20.1 픽션 캐릭터 등장 패널 (PM OPEN-1 의존)

다음 패널은 픽션 캐릭터를 포함하며 **사용자 승인 전**에는 캐릭터 부분을 텍스트만 표시(일러스트 자리에 패턴 + 캘리그래피 한자 "민(民)" 또는 "약(約)" 등으로 대체).

| 위치 | 패널 | 픽션 캐릭터 | 대체 처리 |
|---|---|---|---|
| 인트로 | P6 | 모용손 | 한자 "충(忠)" + 녹색 패턴 |
| 인트로 | P7 | 향이 모자 | 한자 "민(民)" + 베이지 패턴 |
| 인트로 | P9 | 모용손 (대화 카운터파트) | 양만춘 단독 + 인용 부호로만 표시 |
| 엔딩 | E5 | 향이 어머니 | 한자 "휴(休)" + 따뜻한 베이지 |
| 엔딩 | E7 | 향이 | 한자 "약(約)" + 활 실루엣만 |

승인 후 일러스트 교체 시 본 표의 셀을 갱신.

### 20.2 컷씬 패널 공통 레이아웃

## 21. 반응형 / 윈도우 리사이즈 거동 (Responsive)

### 21.1 윈도우 크기 시나리오

| 윈도우 크기 | 스케일 | letterbox |
|---|---|---|
| 1920x1080 (FHD) | 1.000 | 없음 |
| 1600x900 (HD+) | 0.833 | 없음 (16:9) |
| 1366x768 (HD) | 0.711 | 없음 (16:9) |
| 1280x720 (HD) | 0.667 | 없음 (16:9) |
| 2560x1440 (QHD) | 1.333 | 없음 (16:9) |
| 3840x2160 (4K) | 2.000 | 없음 (16:9) |
| 1920x1200 (16:10) | 1.000(w), 1.111(h) → min=1.0 | 상하 60px 띠 |
| 1024x768 (4:3) | 0.711(h*9/16=576), min=0.711 | 좌우 256px 띠 |

### 21.2 최소 윈도우 크기

- **권장 최소**: 1280×720
- **절대 최소**: 1024×576 (이하 시 경고 다이얼로그)

### 21.3 글씨 크기 100/125/150% 대응

본 문서의 모든 베이스 pt는 100% 기준. 125% 시 모든 텍스트 폰트 pt가 1.25배. 150% 시 일부 컴포넌트는 자동 재배치:

- **메인 메뉴**: 버튼 2열 재배치 (DECISION-D-014 참고)
- **좌패널**: 유닛 카드 일부 스크롤 (5개 → 4개 표시 + 스크롤바)
- **도감 카드 리스트**: 1줄 → 1.5줄 행 높이 증가, 가시 카드 수 감소

### 21.4 letterbox 영역 처리

- 색: 순수 검정 `#000000`
- 외곽선 없음
- 게임 영역 밖 입력은 무시 (마우스 클릭 등)

## 24. 인터랙션 표준 (Interaction Standards)

### 24.1 클릭 응답 시간

| 동작 | 응답 시간 |
|---|---|
| 버튼 호버 시 시각 반응 | 100ms 이내 |
| 클릭 시 함몰(눌림 효과) | 80ms |
| 클릭 후 화면 전환 | 200ms 이내 (페이드)  |
| 유닛 배치 시 캔버스 반영 | 50ms 이내 |
| 토스트 알림 표시 | 200ms 페이드인 |

### 24.2 호버 / 포커스 / 활성 / 비활성 상태

모든 버튼·카드는 4가지 상태:

| 상태 | 외곽선 | 배경 | 글씨 |
|---|---|---|---|
| 기본 | 1px 갈색(#6B4A2B) | 베이스 색 | 기본 색 |
| 호버 | 2px 골드(#D4A84A) | 베이스 +5% 밝기 | 기본 색 |
| 포커스 (키보드) | 2px 청(#2D5A8C) 점선 | 베이스 색 | 기본 색 |
| 활성/눌림 | 1px 갈색 | 베이스 -10% 밝기 | 기본 색 |
| 비활성 | 1px 회색(#6E6E6E) | 회색 70% | 회색 |

### 24.3 키보드 네비게이션

- **Tab**: 다음 컴포넌트 포커스
- **Shift+Tab**: 이전 포커스
- **Enter**: 포커스된 버튼 활성
- **Esc**: 모달 닫기 / 이전 화면
- **화살표**: 그리드 형 컴포넌트 (스테이지 카드, 도감 카드) 이동

### 24.4 마우스 vs 키보드 동등성

모든 동작은 마우스로 가능 (DECISION GDD §12.1). 키보드 단축은 보조.

### 24.5 햅틱 / 사운드 피드백 (저비용)

- 호버: 미세한 "톡" 효과음 (선택 ON/OFF)
- 클릭: "딸깍" 효과음
- 잘못된 입력: "삐" (자원 부족 등)
- 성공: "딩" (별 페이드인 등)
